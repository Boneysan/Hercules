# Quest — The Royal Banquet

#custom #campaign #quest

> The party attend a feast meant to unify the kingdom and discover that every table setting is a battlefield.

- **Type:** main (political threshold and assassination set-piece)
- **Level band:** 180-205
- **Quest-giver:** [[../NPCs/Royal_Guard_Commander]]
- **Key NPCs:** [[../NPCs/Kronecker_G_Heine]], [[../NPCs/Bijou]]
- **Frames:** Episode 16.1 banquet politics as the war-council threshold for Act IV.

## Spaces
- **Threshold / Separation:** the banquet hall doors closing behind the party; weapons peace-bound, words made dangerous.
- **Dream-landscape / Initiation:** the banquet floor, where table placement, dance partners, and whispered accusations are the dungeon rooms.
- **Climax space:** the upper gallery when the assassination attempt turns the court into a kill box.

## Quest object
**The Red Command Pin** — Elric's temporary authority token. It lets the party command guards, but every use is recorded. In Arc 19 it proves the army was earned, not assumed.

## Challenge (condition -> consequence)
- If the party map the seating chart before the toast, they identify Bijou's first target and save a royal heir.
- If they chase the assassin without securing exits, nobles die in the panic but Bijou leaves stronger evidence behind.
- If they spend the Pin to command guards publicly, the army trusts them; at least one royal faction resents being bypassed.

## Branching choice
1. **Noble:** protect guests first -> fewer deaths, Bijou escapes to the prison with the command seal.
2. **Pragmatic:** secure the command seal first -> the army survives intact, but the casualty ledger grows.
3. **Suspicious/dark:** let rival nobles expose each other -> maximum evidence, minimum trust.

## Reward
- **Mechanical:** castle access, Red Command Pin, unlocked Underground Prison route.
- **Narrative:** the party learn the state itself can be a dungeon.

## Throughline
- **Plants:** Prontera's army as an Arc 19 ally if earned honestly.
- **Pays off:** Arc 1's Prontera safety fantasy; the first city was never actually safe.
- **"What are you becoming?":** protectors of people, handlers of power, or another faction using panic well?
