# Choice Tracker

#custom #campaign #gm #choices

Use this as the running ledger for choices that should matter later. Update it at the end of each session, not during play.

## How to Use
- Track only choices with a future consequence, ally change, recurring NPC shift, ending gate, or XP/support impact.
- Write the choice as a condition -> consequence, not as a full recap.
- Prefer flags that can be checked quickly in Arc 19: ally present, ally lost, seal strengthened, evidence kept, debt owed, corruption accepted.
- If a choice affects leveling, mark whether it opened a repeatable XP route, closed one, or changed the reward source.
